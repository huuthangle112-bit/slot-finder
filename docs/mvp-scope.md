# MVP Scope

## Must Have

1. PMO dashboard
2. Project selector
3. Team capacity board
4. Squad recommendation table
5. Utilization calculation
6. Slack / float calculation
7. Risk flags
8. What-if replanning

## Should Have

1. Before/after scenario comparison
2. PMO methodology explanation
3. Test scenarios
4. Architecture diagram

## Nice to Have

1. AI-generated recommendation summary
2. CSV export
3. Drag-and-drop assignment

## Out of Scope

1. Real HR integration
2. Real calendar integration
3. Authentication
4. Enterprise permissions
5. Advanced optimization solver
6. Production database
7. Real employee or customer data
