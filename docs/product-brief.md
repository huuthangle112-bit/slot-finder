# The Slot Finder — Product Brief

## Problem

A production team receives incoming customer projects with different sizes, deadlines, and required expertise. Each project requires an interdisciplinary squad. Today, assignment is manual, causing some people to become overloaded, others to be underused, and deadlines to slip because capacity risk is not visible early enough.

## Solution

The Slot Finder is a PMO-style resource planning assistant that recommends feasible squads by comparing project demand against specialist supply, skills, availability, utilization, and schedule slack.

## Primary User

Production Operations Lead / PMO Coordinator.

## Secondary Users

- Project Managers
- Delivery Leads
- Operations Analysts
- Functional Managers

## Definition of Slot

A slot is a feasible assignment window where the right roles, skills, availability, capacity, and schedule slack exist to deliver a project before its deadline without creating unacceptable overload.

## MVP Goal

Help the operations lead select a feasible squad for a new project and understand workload, deadline, and resource risks before approving the assignment.

## Success Criteria

- User can view team capacity.
- User can select an incoming project.
- App recommends a squad.
- App calculates utilization.
- App calculates slack.
- App flags risk.
- App supports what-if replanning.
